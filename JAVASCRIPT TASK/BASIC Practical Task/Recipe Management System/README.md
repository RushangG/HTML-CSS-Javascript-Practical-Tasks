# Task: Building a Recipe Management System

Brief Description: You are tasked with building a Recipe Management System using JavaScript. This system will allow users to manage recipes by adding, editing, deleting, and listing recipes. It will include features for categorizing recipes, searching by ingredients, and saving recipes to local storage. Asynchronous operations will simulate fetching and saving data, and error handling will be implemented to manage potential issues gracefully.






# How to Use

1. Add your recipes details

   a) Recipe Name

   b) category

   c) Ingredients

   d) Instructions

   add recipe button to save the recipe in local storage.

2. after adding recipe you can see the recipe in the list of recipes.

   a) apply filter to see the recipes of specific category.

   b) Also search recipe base on ingredients.

3. edit recipe by clicking on edit button and update the recipe details.

4. delete recipe by clicking on delete button and remove the recipe from local storage.

# Features

## basic CRUD operations for recipe management.

      Add , edit, delete and filter recipes based on category and search recipes based on ingredients.
