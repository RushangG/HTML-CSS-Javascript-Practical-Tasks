# Practical Task: Simple Task Manager Application

Develop a Simple Task Manager application using JavaScript that allows users to add, view, update, and delete tasks. This project will help you practice and understand the usage of various JavaScript array methods in a practical context.

# Description

The Simple Task Manager application will consist of a user interface that allows users to manage their tasks efficiently. Each task will have properties such as id, description, and completed status. The application will utilize various JavaScript array methods to perform operations on the list of tasks.

Features

Add New Task
Users can add new tasks to the list by providing a description.
Each new task will be appended to the task list array.

View Tasks
Display the list of tasks, showing their description and completion status.
Users can see both completed and incomplete tasks.

Update Task
Users can update the description of existing tasks.
Toggle the completion status of tasks (mark as complete/incomplete).

Delete Task
Users can remove tasks from the list.

Filter Tasks
Users can filter tasks to view only completed or only incomplete tasks.

## How to Use

1). Add your task details

    A) Task description

    b) status Completed or Not Completed

Add button to save the task in local storage.

2. Base on status filter the tasks.
   completed or Not completed.

3. edit task by clicking on edit button and update the task details.

4. delete task by clicking on delete button and remove the task from local storage.
