# Task: Implementing a Text Analysis Tool

Brief Description: You are tasked with building a JavaScript tool that analyzes text input to provide various insights such as character count, word count, and frequency of each word. This tool will utilize functions for processing text, arrays/objects for storing and manipulating data, string methods for parsing and analyzing text, and variables to manage input and output.

# How to Use

1. Input your text into the provided text area.

2. Click the "Analyze" button to process the text.

3. The tool will display the following insights:
   - Total character count
   - Total character without spaces count
   - word count
   - unique word count
   - Frequency of each word in the text
