# Task: Display and Search a List of Users in a Table Using External API

# Objective:

Create a JavaScript application that fetches a list of users from an external API, displays the users in a table, and allows the user to search through the list by name.

## Taken a API from Here - https://jsonplaceholder.typicode.com/

# Requirements:

## User Interface:

A search input field to filter users by name.

A Click button to trigger the search.

A table to display the list of users with columns for Name, Email, and Address.

## Functionality:

Fetch the list of users from an external API (e.g., JSONPlaceholder).

Display the fetched users in the table.

Filter the displayed users based on the search input.

# How to Use:

1. API used from here - https://jsonplaceholder.typicode.com/users

2. Auto fetch the data from API and display in table. Also Error handling if API not working.

3. For search functionality, enter the name OR Email in search Box

   And Press the Search Button
   OR
   Press Enter Key to filter the data in table.

4. handle the case when no users match the search criteria and display an appropriate message.
