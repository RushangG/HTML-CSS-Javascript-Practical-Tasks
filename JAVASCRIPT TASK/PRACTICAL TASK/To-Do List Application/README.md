# Task : To-Do List Application

# Objective:

## Create a simple To-Do list application that allows users to:

1 Add new tasks.

2 Mark tasks as completed.

3 Delete tasks

# Requirements:

## User Interface:

A text input for adding new tasks.

A button to add the task.

A list to display tasks.

Each task should have a checkbox to mark it as completed.

Each task should have a delete button to remove it.

## Functionality:

Tasks should be added to the list with the input text.

When a task is marked as completed, it should be visually distinct (e.g., strikethrough text).

Tasks can be deleted from the list.

# How to Use:

1. Enter Task and describe it in the input field.

2. When click on checkbox task toggle between completed and not completed.

   Completed task will be shown with strikethrough text and not completed task will be shown with normal text.

3. When click on delete button task will be removed from the list.

4. Also add Edit button to edit the task and update it in the list.

# Other Features:

## Use Class based components to create the application. And Object Oriented Programming concepts to create the application.

## Use class methods and properties to manage the state of the application.

## Use local storage to save the tasks so that they persist even after the page is refreshed.
