# Quote of the Day Application Task: Create an application that fetches and displays a random quote from an API.

# Requirements:

## User Interface:

A button to fetch a new quote.

An area to display the quote and the author.

## Functionality:

Fetch a random quote from a quotes API using Promises or async/await.

Display the fetched quote in the designated area.

Handle errors if the API request fails.

# How to Use

1. When the webpage loads, a random quote will be displayed.

2. Click the "Update Quote" button to fetch and display a new random quote.

3. Handle any errors that may occur during the API request and display an appropriate message to the user.
