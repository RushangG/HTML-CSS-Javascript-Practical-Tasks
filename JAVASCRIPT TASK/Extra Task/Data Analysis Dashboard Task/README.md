# Data Analysis Dashboard

## Task: Develop a data analysis dashboard that processes and displays statistics from a dataset using loops.

### Requirements:

Use loops to calculate and display metrics such as average, sum, minimum, and maximum values.

Visualize data using charts (e.g., bar chart, line chart) generated dynamically from the dataset.

Allow users to filter and interact with the data for deeper analysis.

# How to Use

1. when page loads, using the productdata set.

2. show Average, sum, minimum and maximum values of product price using loops.

3. show bar chart of product title and stock details.

4. show line chart of product title and price details.

5. show pie chart of product stock \* price details.

6. Show table of product data with all details.

7. Filter the product data based on category.

   ### Also filter category data load dynamically in dropdown select box Base on available categories in productdata.

   Show filtered data:

   a) In cards.

   b) In table format.

   c) All charts change based on filtered data.
