# Quiz Application Task: Create a quiz application that allows users to answer multiple-choice questions. 

# Requirements:

## User Interface:

A question displayed with multiple-choice answers.

A button to submit the answer.

A display of the user's current score and question number.

## Functionality:

Present questions one at a time.

Move to the next question after an answer is submitted.

Display the final score after the last question.


# How to Use

1) When webPage loads, the first question will be displayed with multiple-choice answers.

2) Choose an answer and click the "Submit" button to submit your answer.

3) In header show the current score and question number.

4) At last question, after submitting the answer, the final score will be displayed on the webpage.

5) Also after each question, display a message indicating whether the answer was correct or incorrect.
