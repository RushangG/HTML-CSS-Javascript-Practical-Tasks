# Countdown Timer

# Task: Create a countdown timer that counts down from a given number of seconds.

## Requirements:

Use setInterval to decrement the countdown value every second.

Display the remaining time on the webpage.

Stop the countdown when it reaches zero and display a message.

# How to Use

1. Enter positive number of seconds in the input field.

2. Click the "Start Countdown" button to begin the countdown.

3. countdown will decrement every second and display the remaining time.

4. At zero, the countdown will stop and display a message indicating that the countdown has finished.
