# Task: Implementing a Text Analysis Tool

 Develop a tool that analyzes text input to calculate word frequency, average word length, and most common words.

Requirements:

Use array methods to process and manipulate text (e.g., split, map, reduce).

Display statistics such as word count, average word length, and list of common words.

Handle punctuation, case sensitivity, and special characters appropriately.


# How to Use

1. Input your text into the provided text area.

2. Click the "Analyze" button to process the text.

3. The tool will display the following insights:
   - Most common words
   - Average word length
   - word count
   - Total character count
   - Total character without spaces count
   - unique word count
   - Frequency of each word in the text
