# Task: Interactive Photo Gallery

## Task: Create an interactive photo gallery that allows users to view, add, and delete photos.

### Requirements:

Display a grid of photos using DOM manipulation.

Add functionality to view a larger version of a photo in a modal when clicked.

Allow users to add new photos by providing a URL.

Implement a delete button for each photo to remove it from the gallery.

# How to Use

1. When the page loads, a grid of photos will be displayed.

2. Add url of photo add new photo in gallery.

3. New image will be added in gallery And auto adjust the grid layout.

4. Also click on any photo to view a larger version in a modal.
   a) model will have close button to close the modal.
   b) click on delete button to remove the photo from the gallery.

5. In gallery click on delete button to remove the photo from the gallery.

6. Images store in localStorage with key name "galleryImages" and value is the photo data in JSON format

7. Again refresh the page and check the gallery images are still there because of localStorage.
