# To-Do List with Drag-and-Drop

## Task: Create a to-do list application with drag-and-drop functionality to reorder tasks.

### Requirements:

Allow the user to add new tasks.

Implement drag-and-drop to reorder tasks.

Update the task order in the DOM based on user actions.

# How to Use

1). Add your task details

    A) Task description

    b) status Completed or Not Completed

Add button to save the task in local storage.

2. Base on status filter the tasks.
   completed or Not completed.

3. edit task by clicking on edit button and update the task details.

4. delete task by clicking on delete button and remove the task from local storage.

5. Drag and drop the task to reorder the tasks in the list.
   Also reorder the tasks in local storage based on the new order.

   If refresh the page still the tasks will be in the new order.

   Use Event DragStart , DragOver and Dropend to implement the drag and drop functionality.

# Features

## basic CRUD operations for task management.

      Add , edit, delete and filter tasks based on status.

      Drag and drop functionality to reorder tasks in the list.
