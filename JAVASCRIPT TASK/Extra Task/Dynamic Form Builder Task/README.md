# Dynamic Form Builder

## Task: Create a script that dynamically builds and appends form elements based on user input.

### Requirements:

Use prompt to get the number and type of form elements (e.g., text input, checkbox).

Dynamically create and append the form elements to the DOM.

Display the form on the webpage.

# How to Use

        (
            NOTE : Please open in chrome or firefox browser for better experience.
              Prompt-box  will not work in vs code extension browser input.
        )

1.  first click on the Create New Form button.

2.  in prompt enter the number of input fields you want to create.

3.  Form Builder fill the form with the following details:

    a) Input Type: select the input type you want to create.

    b) Input Label: enter the label for the input field.

    c) Input Placeholder: enter the placeholder for the input field.

    # For checkbox and radio input type

    3.1) input type for "checkbox" and "radio" input type

after filed label name. than click on Add to form button ,

         a) one promt ask number of option in checkbox or radio input type.

         b) than prompt ask for option label name one by one.

         c) add relvent options.

4.  after correct form builder input show fully created form with submit button.

5.  Input Form : filed all details in the form and click on submit button.

6.  check the console And localStorage for the submitted form data.

# Other Functionality

7.  save dynamic form data in localStorage with key name "dynamicFormData" and value is the form data in JSON format

    store like : label : value

    key: value

# Again click on Create New Form button and create new form with different input fields and submit the form data.
