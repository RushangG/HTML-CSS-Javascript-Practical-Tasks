# Guess the Number Game Task: Create a game where the user has to guess a randomly generated number within a certain range. 

## Requirements:

### User Interface:

An input field to enter the guess.

A button to submit the guess.

A display area to show hints (e.g., "Too high", "Too low") and the number of attempts.

### Functionality:

Generate a random number between 1 and 100.

Check if the guess is correct and provide hints.

Track the number of attempts and display it.

Allow the user to play again after guessing correctly.


# How to Use

1) The game will generate a random number between 1 and 100.

2) The user will enter their guess in the input field and click the "Submit" button.

3) The game will check the guess and provide hints if the guess is too high or too low.

4) Also Show the number of attempts made by the user.

5) If the user guesses the correct number, display a success message and provide an option to play again.

6) If the user wants to play again, reset the game and generate a new random number.
