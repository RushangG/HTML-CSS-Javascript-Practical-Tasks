# Image Carousel Task: Create an image carousel that cycles through a set of images. 

## Requirements:

### User Interface:

A container to display images.

Buttons to navigate to the previous and next images.

### Functionality:

Display images one at a time.

Cycle through images using the previous and next buttons.

Implement automatic cycling through images every few seconds.


# How to Use

1) Image carousel will automatically cycle through the images every few ( 4 seconds ) seconds.

2) when clicking the "Next" button, the next image will be displayed.
    
    Also setTimeout Clear using TimeID and Than again setTimeout start automatic cycling through the images every few seconds.

3) when clicking the "Previous" button, the previous image will be displayed.

   Also setTimeout Clear using TimeID and Than again setTimeout start automatic cycling through the images every few seconds.
